# F2: Open-source procedural world generators

## Findings

### [1] Azgaar Fantasy Map Generator (FMG) is a free web app for creating and editing fantasy maps, with desktop installers for Linux/Windows/macOS on each GitHub release and a Nix flake entry point (`nix run github:Azgaar/Fantasy-Map-Generator`).
- quote: "Azgaar's Fantasy Map Generator is a free web application that helps fantasy writers, game masters, and cartographers create and edit fantasy maps."
- url: https://cdn.jsdelivr.net/gh/Azgaar/Fantasy-Map-Generator@master/README.md
- source_type: primary
- published: unknown (README as of master, retrieved 2026-09-23)
- confidence: high

### [2] FMG's world object model (PackedGraph) is Voronoi-cell-centric: each cell carries height, terrain type, river id, feature id, flux, suitability, population, culture, biome, burg, religion, state, province, good, and market ids, plus neighbor and route-link maps; top-level collections include rivers, relief, biomes, features, burgs, states, cultures, routes, religions, zones, markers, ice, provinces, goods, markets, deals, and journeys.
- quote: "cells: { i, c, v, p, b, h, t, r, f, fl, s, pop, conf, haven, g, culture, biome, harbor, burg, religion, state, area, province, good, market, routes }"
- url: https://cdn.jsdelivr.net/gh/Azgaar/Fantasy-Map-Generator@master/src/types/PackedGraph.ts
- source_type: primary
- published: unknown (current master TypeScript types, retrieved 2026-09-23)
- confidence: high

### [3] FMG GIS wiki documents the per-cell GeoJSON export property set as id, height, biome, type (feature type e.g. island or lake), population, state, province, culture, religion, and neighbors — matching Mapedi's semantic layers (height/environment/culture/religion/country/province) almost 1:1.
- quote: "Each feature carries these properties: id, height, biome, type (feature type, e.g. island or lake), population, state, province, culture, religion and neighbors."
- url: https://raw.githubusercontent.com/wiki/Azgaar/Fantasy-Map-Generator/GIS-data-export.md
- source_type: primary
- published: unknown (wiki; screenshots dated 2019-09, content still current)
- confidence: high

### [4] FMG State entities include i/name/expansionism/capital/type/center/culture/coa (coat of arms), optional lock/removed/pole/neighbors/color/cells/area/burgs/rural/urban/campaigns/diplomacy/formName/fullName/form/military/provinces, and numeric fields salesTax, pollTax, treasury — i.e. political simulation (diplomacy, wars, tax) is part of the core object model, not just drawing.
- quote: "export interface State { i: number; name: string; expansionism: number; capital: number; type: string; center: number; culture: number; coa: Emblem; ... salesTax: number; pollTax: number; treasury: number; ... }"
- url: https://cdn.jsdelivr.net/gh/Azgaar/Fantasy-Map-Generator@master/src/generators/states-generator.ts
- source_type: primary
- published: unknown (current master, retrieved 2026-09-23)
- confidence: high

### [5] FMG state generation expands from capitals with multi-cost Dijkstra-like growth (culture match −9, population suitability, biome cost by state type, height/sea/mountain crossing penalties by type Naval/Nomadic/Highland/Lake/River, river flux cost, coastline cost) and then generates campaigns (War/Conflict/Campaign/Invasion/Rebellion/Conquest/Intervention/Expedition/Crusade), diplomacy (Ally/Friendly/Neutral/Suspicion/Rival/Vassal/Suzerain/Enemy), and state forms (Monarchy tiers Duchy→Empire, Republic/Union/Theocracy/Anarchy) with culture-base-specific names (Khanate, Shogunate, Caliphate, Emirate, Tsardom).
- quote: "const totalCost = p + 10 + cellCost / states[s].expansionism;"
- url: https://cdn.jsdelivr.net/gh/Azgaar/Fantasy-Map-Generator@master/src/generators/states-generator.ts
- source_type: primary
- published: unknown (current master, retrieved 2026-09-23)
- confidence: high

### [6] FMG Culture entities have type ∈ {Generic, Hunting, Highland, River, Lake, Naval, Nomadic} and selectable culture sets: world (max 32), european (15), oriental (13), english (10), antique (10), highFantasy (17), darkFantasy (18), random (100) — including full fantasy-race sets (Elves, Dark Elves, Dwarves, Goblins, Orcs, Giants, Draconic, Arachnid, Serpents) with type-specific placement sort functions (e.g. Dwarves favor height, Elves favor forest biomes).
- quote: "export const CULTURE_SETS: Record<string, { name: string; max: number; probability: number }> = { world: { name: \"All-world\", max: 32, probability: 10 }, european: { name: \"European\", max: 15, probability: 10 }, oriental: { name: \"Oriental\", max: 13, probability: 2 }, english: { name: \"English\", max: 10, probability: 5 }, antique: { name: \"Antique\", max: 10, probability: 3 }, highFantasy: { name: \"High Fantasy\", max: 17, probability: 11 }, darkFantasy: { name: \"Dark Fantasy\", max: 18, probability: 3 }, random: { name: \"Random\", max: 100, probability: 1 } };"
- url: https://cdn.jsdelivr.net/gh/Azgaar/Fantasy-Map-Generator@master/src/generators/cultures-generator.ts
- source_type: primary
- published: unknown (current master, retrieved 2026-09-23)
- confidence: high

### [7] FMG Religion entities are typed Folk | Organized | Cult | Heresy with form (Shamanism, Animism, Polytheism, Monotheism, Dualism, Syncretism, Pantheism, Non-theism, Philosophical, Ethical, Deism, Henotheism, Cult, Dark Cult, Sect, Heresy), deity name, expansion mode (global | culture | state), expansionism, origins tree (heresies spawn on Organized boundaries with gauss(0,1,0,3) count), and 14 naming approaches (e.g. "Being + of + Genitive", "Color + Animal", "Supreme + ism").
- quote: "type: \"Folk\" | \"Organized\" | \"Cult\" | \"Heresy\";"
- url: https://cdn.jsdelivr.net/gh/Azgaar/Fantasy-Map-Generator@master/src/generators/religions-generator.ts
- source_type: primary
- published: unknown (current master, retrieved 2026-09-23)
- confidence: high

### [8] FMG River entities track source, mouth, parent, basin, length, discharge (m3/s), width and sourceWidth (km), widthFactor, type (River/Creek/Brook/Stream/Fork/Branch), cell path, and optional meander points; generation fills depressions, drains precipitation flux (MIN_FLUX_TO_FORM_RIVER = 30), models lake inlets/outlets, optional fluvial erosion (downcut, max 5 height units), and defines navigability as flux ≥ MIN_NAVIGABLE_FLUX = 100.
- quote: "export const MIN_FLUX_TO_FORM_RIVER = 30; export const MIN_NAVIGABLE_FLUX = 100;"
- url: https://cdn.jsdelivr.net/gh/Azgaar/Fantasy-Map-Generator@master/src/generators/river-generator.ts
- source_type: primary
- published: unknown (current master, retrieved 2026-09-23)
- confidence: high

### [9] FMG Route entities are free paths grouped as roads | trails | searoutes (plus custom groups), built via Urquhart graphs on burg points + A* pathfinding with land cost = distance² × habitability × height × connection × burg modifiers and water cost scaled by terrain type (coastline 1, sea 1.8, open sea 4, ocean 6, far ocean 8); sea routes may only exit ports through their haven and follow navigable rivers along actual river course; routes are named via burg+suffix / prefix+suffix models and can be locked against regeneration.
- quote: "roads: { burg_suffix: 3, prefix_suffix: 6, ... }, trails: { burg_suffix: 8, prefix_suffix: 1, ... }, searoutes: { burg_suffix: 4, prefix_suffix: 2, ... }"
- url: https://cdn.jsdelivr.net/gh/Azgaar/Fantasy-Map-Generator@master/src/generators/routes-generator.ts
- source_type: primary
- published: unknown (current master, retrieved 2026-09-23)
- confidence: high

### [10] FMG export surface is dual-format: raster/vector image download as .svg, .png, .jpeg (with tile split + zip and PNG/JPEG scale), and data export as GeoJSON (cells, routes, rivers, markers, zones — geographic lon/lat per Options → Configure world) or JSON (full, minimal, pack cells, grid cells) which the UI describes as "an API replacement"; native save is a proprietary *.map* file loadable via Load, with machine / Dropbox / browser storage and URL load.
- quote: "Export to GeoJSON ... cells routes rivers markers zones ... Export To JSON ... full minimal pack cells grid cells ... Export in JSON format can be used as an API replacement."
- url: https://azgaar.github.io/Fantasy-Map-Generator/
- source_type: primary
- published: unknown (live app UI, retrieved 2026-09-23)
- confidence: high

### [11] FMG is mid-migration from vanilla JavaScript to TypeScript with a declared four-layer target architecture (world data and styles as state, generators as model, editors as controllers, renderers as view); the repo already splits src/modules/*-generator.ts (heightmap, cultures, religions, river, routes, states, provinces, burgs, markers, military, names, zones, ice, lakes) from src/renderers/draw-*.ts and src/controllers/*-editor.ts, and a large heraldic emblem subsystem (charges/ordinaries/shields/templates).
- quote: "The application is conceptually divided into four main layers: world data and styles (state), generators (model), editors (controllers), renderers (view)."
- url: https://cdn.jsdelivr.net/gh/Azgaar/Fantasy-Map-Generator@master/README.md
- source_type: primary
- published: unknown (README + repo file listing via jsDelivr, retrieved 2026-09-23)
- confidence: high

### [12] Red Blob Games mapgen2 (Apache-2.0, JavaScript, delaunator-based Voronoi) is an open-source island-style procedural generator explicitly cited as a precursor/peer of Azgaar FMG; it generates volcanic-island terrain for Realm of the Mad God and is seed/parameter-shareable via URL, but intentionally lacks states/cultures/religions — the author notes those as possible extensions and points users to Azgaar FMG for the fuller fantasy stack.
- quote: "Also take a look at Azgaar's Fantasy Map Generator, an amazing open source project with features discussed on github, reddit, blog, wiki, and trello."
- url: https://www.redblobgames.com/maps/mapgen2/
- source_type: primary
- published: 2017-09-01 (last modified 2026-04-28)
- confidence: high

### [13] Red Blob Games mapgen4 (open source, mostly inactive but actively restyled 2023–2025) is a paint-then-simulate generator: user paints mountains/valleys/oceans, then the tool simulates evaporation, wind, and rainfall to derive biomes and rivers; 2025 work includes a WebGL2 terrain renderer rewrite, a river shader rewrite, trade-route experiments, and finer elevation painting — a direct workflow contrast to FMG's generate-then-edit model.
- quote: "Pick a starting seed, then paint mountains, valleys, and oceans on the map! It will simulate evaporation, wind, and rainfall to determine biomes and rivers."
- url: https://www.redblobgames.com/maps/mapgen4/
- source_type: primary
- published: 2018-07-20 (changelog through 2025-10-13)
- confidence: high
