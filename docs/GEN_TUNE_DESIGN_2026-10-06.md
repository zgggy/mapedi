# 生成/细化三项参数设计（2026-10-06 · 待拍板）

> 用户原话（2026-10-06）：
> ①「平整参数不是让全局平整，而是在顶峰和深海还都会出现的情况下，尽量让接近海拔 0 的
>   高度值出现的多一些——0 = 均匀比例，1 = 占比 95% 以上，整体可以按照正态分布来设计」
> ②「基于已有生成的海岸线经常特别零碎——可以有破碎感，但不能如此零碎」
> ③「生成方式要考虑所基于的原始高度图的已有高度——参数 0 = 现在的效果（不考虑原始、
>   直接重新生成），1 = 尽可能贴近原始高度图。例：先画几个高度为 1 的元素，再在大陆
>   中间点几个不同高度的山峰（顶峰/山地），再在海洋中间画远海/深海——生成后这些绘制
>   的高度基本上还在那里、变化不大，其他地方自由发挥。」

本文档 = 设计与拍板稿，**不含实现**。三项都作用于现有「基于已有」管线（v7 Poisson
约束生成），第一项（平整）同时作用于常规「生成高度图」。

## 现状管线（v7，三项设计的挂点）

```
手绘骨架 (h0) ──mask──► ① 同源形态场 f = terrainFieldFor (与 buildTerrain 同链)
                              │
② Poisson 低频修正：h = f − u·w(d)  （u=岸线值延拓；w=距岸衰减）
                              │
③ 分布刻度（=「平整」参数挂点）：陆/海各自分位映射 [1,64]/[−63,0]
                              │
④ 海岸碎渣清理（=「破碎度」挂点）：碎块归并 + 毛刺
                              │
                        写 cell.height
```

## 一、「平整」参数重设计（分布集中度）

### 语义
- 参数 t∈[0,1]（沿用现有「平整」旋钮位置与值域）。
- **t = 0**：均匀比例（=现状效果：陆 [1,64] / 海 [−63,0] 逐档均匀铺满）。
- **t = 1**：接近海拔 0 的高度值占比 **≥95%**；同时**顶峰 64 与深海 −63 每次都出现**
  （尾部非零质量）。
- 中间值连续过渡。

### 数学设计：截断正态 + 宽尾混合（分位反演）
纯正态不行：σ 小到 95% 落在 ±8 内时，64 是 16σ 事件≈永不出现——与「顶峰深海还都会出现」矛盾。故用**混合分布**：

```
目标分布 H(t) = (1 − m)·N(0, σ(t))  +  m·Uniform(−63, 64)      （陆侧用 [1,64]、海侧 [−63,0] 对称处理）
```

- **主体（1−m）**：0 中心正态——参数 0..1 的集中度来源；
- **宽尾（m ≈ 2%）**：均匀铺到端点——保证**顶峰/深海每次出现**（尾部总有 ≥1 格）；
- **σ(t)**：几何插值 `σ(t) = σ0 · (σ1/σ0)^t`；
  - σ0 ≈ 37（≈[−63,64] 均匀分布的等效标准差）→ t=0 观感=均匀；
  - σ1 ≈ 4.5（使 P(|h|≤8)≈95%+）→ t=1 集中在 0 附近；
- **落地 = 分位反演查找表**：把 H 的 CDF 数值化（1024 分位），生成时
  `h = F⁻¹(rank)`（rank=该格在同侧域 f 的秩分位）——替换现有 gamma 幂弯，
  其余管线不动。

### 旋钮语义表
| t | h 分布（示意） | 观感 |
|---|---|---|
| 0 | 均匀铺满 | 现状（0=均匀比例，用户定义） |
| 0.5 | 0 附近明显集中、两端渐稀 | 常规地形（平原多、山海少） |
| 1 | ≥95% 在 ±8 以内、仍有零星 64/−63 | 大平原世界，山峰/海沟点缀 |

### 断言草案
- t=0：档分布直方图 ≈ 均匀（各档差 ≤±15%）；
- t=1：|h|≤8 的格占比 ≥95%；`max(h)=64 ∧ min(h)=−63` 为真；
- t 单调：集中度（峰度/0 邻占比）随 t 严格增。

## 二、海岸破碎度（碎但不零碎）

### 语义
海岸**允许破碎感**（岛屿、峡湾），但存在**最小特征尺度**：碎岛/碎湾不小于 N 格。
现有碎渣清理（<30 格无手绘归并）是"清渣"，不约束**有手绘/大片区**的边缘碎化。

### 设计：输出端尺度约束（与源头 coastBreak 叠加）
1. **碎岛尺度**：连通陆域 < `K(t)` 归并入海（含手绘的小岛豁免逻辑保留）；
   `K(t)` 由现有「海岸破碎」旋钮 coastBreak ∈[0,1] 映射：
   `K = round(Kmax·(1−coastBreak) + Kmin·coastBreak)`，Kmax≈220 格（平滑海岸）、
   Kmin≈40 格（允许碎岛，但仍非"零碎"）。
2. **碎湾收口**（morphological closing）：凹入陆地的水湾若**周界 < W 格**（同映射）→
   填平（防"锯齿海湾"）；凸出的细半岛同理归并（防"毛刺"）。
3. **岸线平滑**：沿岸 1–2 轮切向移动平均（法向位移 ≤2 格），强度 ∝(1−coastBreak)
   ——保留破碎感的"形"，去掉"锯齿/须边"。
4. 手绘豁免：含手绘原格的域不归并（现规则保留）；护岸开时岸线平滑关闭。

### 断言草案
- 碎岛（无人工来源）全域 <K → 不存在；
- coastBreak=0 与 1 的岸线曲率分布显著不同（破碎感保留 ≠ 光滑成圆）；
- 手绘小岛（任意大小）100% 保留。

## 三、「贴近原始高度分布」参数（锚定，t₀∈[0,1]）

### 语义（用户例子即验收故事）
- t₀ = 0：**现状**（不考虑原始高度图，重新生成后手绘处也面目全非）；
- t₀ = 1：**尽可能贴近**——手绘过的格（锚点）生成后高度变化 ≈0（整数取整内）；
- 中间值：锚点权重渐变；**其余格自由发挥**（f 形态场照常）。

### 锚点定义（草案）
- **锚 = 手绘过的格** = 高度区间元素中非空档的格（h0 ≠ 0 的格集）；
- 例外：手绘「浅滩 0 值」会被判为非锚（h0=0=默认值无法区分）——**待拍板**（P3）；
- 锚值 = h0（用户绘制值，如 1 / 61 顶峰 / −50 远海）。

### 数学设计：多锚点 Poisson 软约束（**复用 v7 架构**，实现成本低）
v7 的岸线修正 = 单边界约束的 Poisson（h=f−u·w，u=边界值延拓）；
锚定 = 同构推广为**多点 Dirichlet 软约束**：

```
1. u = 锚点值的延拓（BFS 最近锚值 + 同域平滑——与 v7 的 u 完全同一函数，仅源不同：岸格 → 锚格）
2. w_i = t₀ · K(dist_i / R)          （K=光滑核：1−smoothstep(0,1,x)；R≈12 格影响半径）
3. h = f − u·w     ⇒   t₀=1 时锚点 h=f−(f−h0)=h0（锁定）；t₀=0 时 h=f（现状）
```

- 锚点邻域被"拖"向锚值（半径 R 内渐变），**远处完全自由** ✓ 对应"其他地方自由发挥"；
- 与护岸开关独立（锚=点约束、护岸=轮廓约束）；与「基于已有」总开关的关系：
  锚定只在「基于已有」开时生效（该入口=读取手绘骨架的唯一入口）；
- 普通「生成高度图」（不基于已有）不受影响（h0=全 0 无锚）。

### 用户例子走查（t₀=1）
1. 画高度 1 的平地元素、大陆中点几个山峰（顶峰/山地）、洋中画远海/深海；
2. 「基于已有」两击生成（护岸任选）；
3. 预期：这些格高度 = 所画值（±0~1）；山峰周围山系自然生长（R 外自由）；
   海底自然起伏；未画区域与常规生成同款。

### 断言草案
- t₀=1：锚点 |h_gen − h0| ≤1（整数取整），保真率 ≥99%；
- t₀=0：与 v7 现状输出**逐位一致**（回归基线）；
- 中间值：锚误差随 t₀ 单调减；锚邻域外与 f 的秩相关 ≥0.9（自由发挥）。

| 旋钮 | 新语义 | 范围 | 建议默认 |
