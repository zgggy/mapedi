## 1. 优点（还债与建设中不得破坏的）

1. **单源纪律**：`terrainFieldFor/erodeAndDespike`（与 buildTerrain 同链=「效果一样」的
   代码保证）、`unwrapXAgainst/projectionPeriodAt`（反馈层与件渲染同链）、`isLayerShown`
   （显隐单点）、`bandColorOf`（档色单点）、`tolerances.ts`（容差单源）——"两套真相"类
   bug 被结构性消灭。
2. **不变量+量化验收文化**：mask 0 破、锚点误差 0、集中度 pct 1.6→34.7→98.7 单调、
   unwrap 三对照 6.275→0.02、跨线四点命中全等、河谷 145→1574——每轮交付带数字。
3. **诊断先行**：碎渣「还是碎」三修 = 先在用户真实数据上量特征（14 个 4-8 格块）再改，
   四个根因（阈值逃逸/来源判据/顺序/翻转吞岛）逐一实证——盲改被流程拦住。
4. **根因连环作战**：跨线绘制连挖四层（桶不环绕 → 反馈层 unwrap → 周期 y 依赖 →
   逐格语义）；λ·度>1 这类数学过冲被断言当场抓住。
5. **拍板-留痕闭环**：需求 → 设计稿（GEN_TUNE 含 P1-P4 建议）→「开整」→ 实现 → 验收；
   契约变更 AGENTS/RENDER_LOGIC 记日期+原话（显隐、栈序、注记显示均有档）。
6. **数据安全纪律成形**：合成世界验收、快照+undo、手删数据自愈恢复、IDB 事故教训入档。

## 5. 数据模型对照（对《地图编辑器数据模型思考记录》的逐条评估）

> 该文档三公理：①一切数据=元素、一切视图=过滤器；②一切关系=「空间受限」一种机制
> （集合判定+Min/Max+反受限开关），父子/游离/争议区全是参数；③派生关系落盘实体化。

| 议题 | 文档主张 | Mapedi 现状 | 判断 |
|---|---|---|---|
| 元素↔地块引用 | **双向各存一份**、增删同步 | **单向**（Region.cells）+ regionIndex 反向索引（可重建） | **我们更优**：双向=双真相（AGENTS 红线），同步漂移正是本会话多起 bug 的形态；把"为何不做双向"写入反向对话录 |
| 高程派生 | **落盘实体化**（生成即算成普通关联、标脏刷新、可微调） | **实时派生**（flushHeightRegions 重算精确档+显示累积再派生） | 各有对价：文档=统一但改高后过期；我们=实时但派生链是债源（reconcile/面板响应两 bug 出自它）。**吸收点=把派生边界显式化** →《数据真相表》（字段→真相/派生/刷新协议），一次性收 H1+M1 |
| 关系机制 | 统一「空间受限」（含 Max=N 多归属=争议区） | 散字段（parentLayerId 链/allowOverlap/requireAdjacency/placement） | 文档概念数少表达力大；我们已有"反受限开"实体（父层 cells=子并集）但未概念化。**Max=N 多归属（争议区）是最有价值新能力** → 登记 Epic 待拍板（动 parentId→parents[] 全链，不进当前批次） |
| 幂等/性能路线 | 每次编辑全局重算（简单慢） | 定向失效+增量（快但失效族复杂=M1 债） | **我们更优**（文档自认换简单舍性能）；M1 收口=失效表化，不回退全局重算 |
| 视图不进数据模型 | 视图层事务（渲染序/多视图/标签同步）全部剔除 | StyleSet.layerStyles（视图级默认）=正面实证 ✓；`world.layerRenderConfig` 边界模糊 | 基本一致；layerRenderConfig 归类理由（用户创作配置≠视图偏好、需落盘随世界）写入真相表 |
| 高度层地位 | 批量生成的普通元素 | **一等公民玩法**（细化/档位/绘制围绕它） | 用户直觉 > 文档教条；正解=**《高度层专则》显式成文**（特殊=文档化设计决定，不是隐式债） |
| 点线优先原则 | "不要无脑堆面图层，新增信息优先点/线" | 已有 cellMarks 点/路径线先例 | 采纳为 ROADMAP 产品原则 |
| 其他 | 循环受限检测/图层内重叠开关/核心子元素（不聚合） | 链防环 ✓ / allowOverlap ✓ / centerCellId·coreRegionId（不聚合）✓ | 三处均已等价实现，仅词汇对齐 |

**理念 vs 实现总评**：文档理念更清晰优秀（概念数最少→心智负担低），是好的北极星；Mapedi
理念同样明确且在**两处比文档更正确**（拒绝双向落盘、拒绝全局重算），实现明显更鲁棒
（实时/性能/单源），但**显式度不足**——文档把约定写在纸上，我们把很多约定留在代码与对话里
（=H1/M1 债的本质）。

**可吸收清单（按性价比）**：①《数据真相表》立刻做；②约束词汇对齐（只改文档/注释，不动实现）；
③《高度层专则》成文；④多归属/争议区 Epic 登记待拍板；⑤不采纳：双向引用、全局重算。
