# Mapedi 展开区信息架构重构方案（图层/元素 × 四模式）

> **定位**：设计稿——对应 2026-10-02 需求「所有可展开的图层或者元素在任何模式下的内容，都需要更加有条理；
> 整体的、系统的、仔细的分析需求和最终目标，给一个重构方案，包括每个模式下图层展开后有什么、
> 元素展开后有什么、应该怎么组织；信息按重要程度、便捷程度排版」。
> **状态**：方案待拍板（§7 待拍板 D1–D8）。拍板后按 §6 分期实施。
> **约束**：不推翻既有拍板结论（眼睛在检查区、右键只剩复制/删除、生成模式元素行不可展开=子元素功能待重设计、
> 组织模式元素无缩进钮、行单击=选中展开单开互斥）；本方案管的是**展开后的内容与排版**。

---

## 1. 需求与目标

### 1.1 用户原话拆解

| 要求 | 含义 |
|------|------|
| 更加有条理 | 内容要分层、分组、有稳定的阅读顺序，不是平铺 |
| 整体的、系统的 | 四模式 × 图层/元素 = 8 个格子要**一套语法**，不能各自为政 |
| 按重要程度排版 | 高频高值的信息先被看到、先能点到 |
| 按便捷程度排版 | 核心操作一步可达；低频细节折叠但不删除 |

### 1.2 目标（验收即按此）

1. **扫一眼就知道状态**：行内（不展开）能看出显隐/焦点/有无子层等关键状态（L0 层）。
2. **展开第一屏 = 该模式的主任务**：检查=这是什么+怎么微调；生成=怎么产出；绘制=怎么画；组织=怎么排。
3. **八个格子同构**：同一信息（名称/计数/样式/状态）在任何格子里的位置与形态一致。
4. **空态有解释**：不可用的格子给出"为什么"，而不是死一般的沉默。
5. **密度有阶梯**：行 24–32px、字段行 22–26px、组距 6–8px；任何展开区高度可控（检查 ≤ ~320px 常态）。

## 3. 问题分析

| # | 问题 | 证据/表现 |
|---|------|-----------|
| P1 | **重要度倒置**：最高频的"显隐"是占整行的大文字按钮；ID/分类/子层等低频低值 KV 与名称颜色平铺同列；描述常空却固定占 2 行 | InspectSection 快照 |
| P2 | **低频内容常开**：样式面板 8 个控件永远全量展开，占展开高度约 40%，把主信息挤出第一屏 | 展开实测 333–385px |
| P3 | **死信息**：图层的「相邻 —」恒为占位；元素 ID 全量展示（可复制但极少读） | EntityInfoBody |
| P4 | **沉默的空态**：生成模式点元素行完全无反应；绘制模式点图层行无反应——用户不知道是"不支持"还是"坏了" | modeBodyOf / layerExpand |
| P5 | **参数住错地方**：笔刷宽度是全局绘制参数，却在每个元素行里重复一份（改哪个都改全局） | WD draw mpanel |
| P6 | **语义混区**：高度涂改滑块（写数据的绘制动作）出现在检查模式展开区 | InspectSection hsl |
| P7 | **模式间无共享骨架**：切模式=整个展开区重排，身份信息（名称/计数）只在检查里，生成/组织里"这是谁"要靠抬头看行 | 四分支模板互不复用 |
| P8 | **操作与信息混排**：保存（动作）埋在信息流底部，与 KV 同层；没有稳定的"动作条"位置 | EntityInfoBody |
| P9 | **行内信息过瘦（L0 缺失）**：隐藏的层、无配置的层、有子层的层——不展开完全看不出来 | ItemButton 只有色点+名字 |

## 4. 设计原则（本方案的判断标准）

### 4.1 信息分层（L0–L3）

| 层 | 定义 | 承载 |
|----|------|------|
| **L0 行内** | 不展开即见 | 色点、名称、显隐态、焦点态、缩进结构、（拟增）配置态小标 |
| **L1 展开首屏** | 展开后 1 屏内 | 身份（名称/颜色/计数）、**该模式主任务**、动作条 |
| **L2 展开次级** | 同屏靠后或一次点击展开 | 样式参数、描述、相邻、隶属详情 |
| **L3 折叠/后置** | 默认收起 | ID、分类、创建时间类元数据 |

### 4.2 重要 × 便捷矩阵（排版总规则）

| | 高便捷（一步可达） | 低便捷（滚动/展开） |
|---|---|---|
| **高重要（每看必用）** | L0 行内 / L1 首位：显隐、名称、主任务按钮 | L1 固定条：保存（动作条恒在底部） |
| **低重要（偶用）** | L1 中段：计数、隶属、样式入口 | L2/L3 折叠：样式全量、ID、描述细节 |

### 4.3 位置语义（八格统一的纵向骨架）

```
[状态条]  显隐开关 · 焦点/模式徽标 · （元素）隶属入口
[身份区]  名称 · 颜色 · 计数        ←—— 图层/元素、任何模式同形
[主任务区] 本模式的核心内容         ←—— 检查=详情与参数；生成=分支面板；绘制=笔刷；组织=四钮
[次级区]  L2/L3：样式、描述、相邻、ID（可折叠）
[动作条]  保存（仅检查模式有）
```

### 4.4 一致性规则

- 同一字段在 8 格中的**标签、形态、顺序**一致（如"计数"永远紧跟颜色）。
- 控件语法一致：开关=胶囊 toggle、数值=滑块+右值、枚举=分段按钮、动作=圆角钮。
- 空态必有文案（`为什么不可用/为什么是空`），一行 11px dim。

## 5. 逐格规格（目标态：每格有什么、怎么排）

### 5.1 图层行 × 检查

| 序 | 区块 | 内容与排版 | 层 |
|----|------|-----------|-----|
| 1 | 状态条（一行） | 显隐 **胶囊 toggle**（👁/🚫+短词，宽~110px）· 焦点徽标「聚焦中」· 类型徽章（内置/自定义） | L0/L1 |
| 2 | 身份行（一行） | 名称输入（flex）+ 颜色块（30×20）+ 计数徽标「N 元素」右贴 | L1 |
| 3 | **主任务区** | 微调参数：描述（空则收为一行「+ 添加描述」）、**相邻行删除**（层无此概念）、KV 流只留 **子层**（结构相关） | L1 |
| 4 | 样式组 | **默认折叠**为摘要行「边界 0.8 · 平滑 0 · 填充开」，点开展开现全部控件（D1） | L2 |
| 5 | 元数据 | ID、分类 → 折进「详情 ▸」 | L3 |
| 6 | 动作条 | 保存按钮（右对齐、常高 26px、sticky 底） | L1 |

预期高度：常态（无描述、样式收起）≈ **200–230px**（现 333–385px）。

### 5.2 图层行 × 生成

保持三分支结构（这块现状已最有条理），做三件事：

1. 分支头统一：`[策略徽章] 重新撒点 / 生成高度图 / 生成「X」`——徽章即 L0 状态（行内拟增同款小标，D5）。
2. 地形旋钮 9 个改 **3×3 紧凑网格**（现两列长行滚动），组标题「地形」。
3. **elements 无配置分支 = 活空态**：「该层无生成配置——在检查模式设置参数后可再生成」（替掉死板的"该层无生成配置"且无指引）。
4. 路径类（genStrategy 无值、参数存在）：标题行加「生成方法待设计（GEN R7）」徽章，参数照旧（现状行为保留）。

### 5.3 图层行 × 绘制（现在是死格 → 给内容）

图层不能直接画（笔刷落在元素/子层上），所以此格放**绘制上下文**：

| 序 | 内容 |
|----|------|
| 1 | 当前绘制目标说明：「在本层笔刷 = 画到子层『行省』元素上（无子层则直接画本层）」——把 resolveDrawTarget 的语义讲给用户 |
| 2 | 本层显隐快捷 toggle（同检查形态）——防"画了看不见"，与状态栏红字互补 |
| 3 | 高度层特例：显示「高度笔刷」说明 + 涂改入口提示（与元素行联动） |
| 4 | 空态：自由路径层 → 「路径在画布上直接绘制控制点」 |

（若拍板认为图层×绘制应保持不可展开，则至少在**行 hover 出现 tooltip** 解释，杜绝沉默，D4。）

### 5.4 图层行 × 组织

现状四钮+hint 已简洁，补充两项：

1. **层级面包屑**一行：「国家 › 行省」显示当前父链（组织任务的即时上下文）；
2. hint 从"操作「名」的层级与顺序"改为只在按钮禁用时显示原因（禁用态现在只有 title 悬停可见，不可发现）。

### 5.5 元素行 × 检查

| 序 | 区块 | 内容与排版 | 层 |
|----|------|-----------|-----|
| 1 | 状态条 | 显隐胶囊 toggle · **隶属入口**（「隶属 华夏」可点=跳转父元素，接层级设计 D7；不可点时至少高亮） | L0/L1 |
| 2 | 身份行 | 名称 + 颜色 + 「N 地块」 | L1 |
| 3 | 高度元素专属 | interval 徽章「区间 25–36」**只读**；涂改滑块**迁往绘制模式**（P6，D2） | L1 |
| 4 | 描述 | 空则收为「+ 添加描述」 | L2 |
| 5 | KV | 子层元素数（有子层时）、相邻 chips（≤4 + 「+N」展开） | L2 |
| 6 | 元数据 | ID 折进「详情 ▸」 | L3 |
| 7 | 动作条 | 保存（右对齐 sticky） | L1 |

### 5.6 元素行 × 生成

拍板保留"不可展开"（子元素功能待重设计）。本方案只做**消除沉默**（D3）：行 hover 显示 title
「元素级生成待重新设计（2026-10-01 拍板）」；等层级系统的元素 UI 包（HIERARCHY_DESIGN §6.4）落地时再填内容。

### 5.7 元素行 × 绘制

1. **笔刷宽度上移**：它是全局参数 → 移到绘制模式的面板级工具带（或状态栏旁常驻），行内删除（P5，D5 为拍板项：若想就近可保留但标注「全局」）。
2. 行内保留**元素相关**：高度涂改滑块（interval 元素）＋ 洪水填充/设中心等动作入口（若后续恢复）。
3. 常驻一行目标提示：「笔刷 1.5° · 画在「浅滩」上」——把画在谁身上的状态显性化。

### 5.8 元素行 × 组织

保持 ↑↓（拍板：无缩进/提升）。补充与 5.4 同款：禁用原因可见化（不再是 title-only）。
