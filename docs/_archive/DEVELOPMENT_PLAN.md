# Mapedi 开发计划（执行基线 · 对照需求全覆盖）

> 原则：**按本文件顺序推进，不在每个环节向用户要选择。**  
> 需求以 `REQUIREMENTS.md` 为准；冲突时先实现需求文档已决议项。

### 1.2 世界气候 / 行星参数（P5 必做，写入 World）

```ts
ClimateParams {
  axialTiltDeg: number        // 黄赤交角，默认 23.4
  rotationHours: number       // 自转周期，影响科里奥利/风带
  rotationPrograde: boolean   // 顺行/逆行 → 信风/西风带方向
  oxygenLevel: number         // 0.5–1.5，影响动物生成多样性
  baseTemperatureC: number    // 赤道海平面基准均温，默认 28
  oceanHeatCapacity?: number  // 距海降水衰减
}
```

派生（每 cell 缓存，不进文件真相，可重算）：

| 场 | 公式要点 |
|----|----------|
| 温度 | `T ≈ baseT·cos(lat) − lapse·height_m − 极地加强(倾角相关) + 噪声` |
| 风带 | 信风（低纬）/ 西风（中纬）/ 极地东风；`rotationPrograde` 决定东西向 |
| 降水 | 迎风坡沿海↑ + 背风坡雨影 + 距海衰减；河网邻域微增湿 |
| 含氧 | 基准×高度衰减；乘动物容量 |

**环境群系（Whittaker 近似 + 用户点名项）**：至少  
`冰盖` `雪地` `冻土/苔原` `针叶林` `温带森林` `草原` `沙漠` `稀树草原` `雨林` `湿地/沼泽` `海岸滩涂` `海底`  
→ 写为 environment 层 Region 或 cell 上 `biomeId`（推荐：cell 场 + Region 聚合列表）。

**植物**：按 biome+湿度生成聚合区（可重叠权重）；**动物**：按 biome+大陆+含氧；**种族**：与文化邻近的种子扩张。


- 「仅重生成此层」+「级联」勾选列表。
