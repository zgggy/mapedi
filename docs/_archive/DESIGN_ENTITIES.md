# Mapedi 世界观实体与界面 · 详细设计方案

> 版：v0.9 设计稿（**未实施**）· 日期：2026-09-23  
> 配套：现行契约见 `RENDER_LOGIC.md`；竞品调研 `research/fantasy-map-editors/REPORT.md`（旧配套 `REQUIREMENTS.md` / `DESIGN_SPEC.md` 已归档至 `docs/_archive/`，勿当依据）  
> 定位修正：**跑团 / 桌游 / 世界观设定 / 小说** —— 用地图展示设定，而非长文笔记库。

---

## 0. 产品原则（一切设计由此推出）

| 原则 | 含义 | 反例（不要做） |
|------|------|----------------|
| **地图是主界面** | 国家、人物、势力都「长在」球面上；离开地图的设定是二等公民 | 打开就是文档树 / 纯白写作页 |
| **设定 = 类型化实体** | 每个国家是一张「国家卡」的数据源，不是一篇 md | 一个国家 = 一个 Markdown |
| **一实体多视图** | 同一实体可切卡片墙 / 侧栏页签 / 关系图 / 地图锚点 | 每种看法另存一份数据 |
| **展示可切换** | 排列方式（横排卡片 / 左侧页签）是视图偏好，可随时改 | 把某种布局写死进结构 |
| **数据结构优先** | 先定 schema 与关系边，再堆 UI | 先画漂亮面板再补字段 |
| **笔记次要** | 描述/短传是实体上的字段；不做百科长文引擎 | Notion/World Anvil 全文检索中心 |

## 1. 信息架构总览

```text
┌─────────────────────────────────────────────────────────────────┐
│  顶栏：视图（2D/球）· 图层焦点 · 显示模式 · 生成 · 项目            │
├──┬──────────────────────────────────────────────┬───────────────┤
│图│                                              │ 工作区         │
│层│              地 图 视 口（主舞台）              │ （实体列表/     │
│栏│   cell 语义层 · 边界 · 路径 · POI · 选中高亮    │  卡片坞）      │
│  │                                              │               │
├──┴──────────────────────────────────────────────┴───────────────┤
│ 状态条：悬停实体 · 高度 · 比例 · 模式提示                          │
│ 绘制 HUD：笔刷/权重/填充/路径/POI                                  │
└─────────────────────────────────────────────────────────────────┘

按下「实体模式」或选中实体后，主舞台可切到「专视图」（仍可缩略地图钉住）：

  地图模式  ⇄  国家卡片坞  ⇄  人物关系图  ⇄  势力/文化对比  ⇄  路径时间线
       ↑___________ 任意专视图点击实体 → 地图高亮锚点 ___________↓
```

**导航故事（用户路径）**

1. 在地图上用笔刷画出国家 A、B → 工作区出现国家实体  
2. 点 A → **国家卡**（可横排多国 / 左侧页签切国）  
3. 在国家卡里挂人物、盟敌、首都 POI → 切到**人物关系图**，点人物高亮其「活动范围 / 出生地」  
4. 全程地图侧栏保持「当前实体锚点」可见，Esc 回地图编辑

## 2. 数据结构（核心）

### 2.1 与现有模型的关系

```text
Cell（Voronoi 地块）────────── 地理原子（已有）
Region（层内元素）────────── 语义连通块（已有：高度/文化/国家…）
PathFeature（路/河/航）───── 自由曲线（已有）
        │
        ▼  引用 / 聚合（本方案新增）
WorldEntity（世界观实体）──── 国家卡/人物/事件的「真相」
Relation（实体关系边）──────── 盟/敌/附庸/亲缘/隶属…
Anchor（地图锚点）─────────── 实体 ↔ 地理的绑定
ViewPrefs（视图偏好）───────── 卡片排列 / 页签 / 图谱布局
```

> **Region 仍是绘制结果**；**WorldEntity 是设定叙事层**。  
> 国家可以 `regionId` 指向 country 层 Region；也可无 Region（流亡政权、传说国度）仅 POI 锚点。

### 2.2 TypeScript 草案

```ts
/** 实体类型：每类有默认字段模板 + 一种「主视图」 */
export type EntityKind =
  | 'country'      // 国家
  | 'province'     // 行省（可选升格为卡）
  | 'person'       // 人物
  | 'culture'      // 文化/民族
  | 'religion'     // 宗教
  | 'organization' // 组织/教团/公会
  | 'place'        // 地点 POI（城/山/遗迹）
  | 'event'        // 事件（可挂时间）
  | 'species'      // 种族/生物
  | 'artifact';    // 物品/圣物（可选）

export type AnchorKind =
  | 'region'   // 绑定 Region（国家领土、文化分布）
  | 'cells'    // 直接 cell 集合（不建 Region 时）
  | 'point'    // 单点 POI（lon/lat）
  | 'path'     // 绑定 PathFeature（商路、远征）
  | 'none';    // 纯设定、暂无地理

export interface MapAnchor {
  kind: AnchorKind;
  regionId?: string;
  cellIds?: number[];
  point?: { lon: number; lat: number };
  pathId?: string;
  /** 高亮时的主色，默认取实体 color */
  tint?: string;
}

export interface Relation {
  id: string;
  /** 有向：from → to；无向边用双向各存或 flag */
  fromId: string;
  toId: string;
  type: RelType;
  label?: string;       // 「弑父」「附庸」自定义短语
  weight?: number;      // 图谱边粗细 0–1
  startYear?: number;   // 时间线用（世界历）
  endYear?: number;
  attributes?: Record<string, unknown>;
}

export type RelType =
  // 政治
  | 'ally' | 'enemy' | 'vassal' | 'suzerain' | 'atWar' | 'truce' | 'trade'
  // 亲缘 / 人际
  | 'parent' | 'child' | 'spouse' | 'sibling' | 'mentor' | 'rival' | 'member'
  // 叙事
  | 'founded' | 'destroyed' | 'rules' | 'locatedIn' | 'partOf';

export interface WorldEntity {
  id: string;
  kind: EntityKind;
  name: string;
  /** 短名/代码/外号，卡片角标 */
  shortName?: string;
  color: string;
  emoji?: string;
  /** 卡片摘要（一两句，不是长文） */
  summary?: string;
  /** 结构化槽位，按 kind 用 schema 校验（见 2.3） */
  fields: Record<string, string | number | boolean | string[] | null>;
  anchors: MapAnchor[];
  /** 图标/立绘本地引用或 dataURL（可选） */
  portrait?: string;
  attributes?: Record<string, unknown>;
  createdAt: number;
  updatedAt: number;
}

export interface WorldLore {
  entities: WorldEntity[];
  relations: Relation[];
  /** 全局视图偏好（可 per-user 覆盖） */
  viewPrefs: {
    countryDock: 'cards-row' | 'side-tabs' | 'grid';
    personGraph: 'force' | 'radial' | 'orbit-country';
    showOnMap: Record<EntityKind, boolean>;
  };
  /** 世界历：最小可用年；后续可接 Fantasy Calendar 子集 */
  calendar?: {
    eraName: string;
    year: number;
    month?: number;
  };
}
```

### 2.3 分类型字段模板（`fields` schema）

| Kind | 主视图 | 必填字段 | 常用字段 |
|------|--------|----------|----------|
| **country** | 国家卡坞 | 政体、首都(placeId) | 格言、人口、民族、宗教、科技水平、军力、附庸列表 |
| **person** | 关系图 | 所属(countryId/groupId) | 职业、种族、年龄/生卒年、势力、头衔、特质标签[] |
| **culture** | 地图分布+对比卡 | — | 语言、价值观、服饰、饮食、禁忌[] |
| **religion** | 地图分布+神系简图 | — | 神祇[]、教义摘要、圣地(placeId[]) |
| **organization** | 成员图 | — | 总部、规模、目标 |
| **place** | POI 卡+地图 | 锚点 point/region | 类型（城/山/遗迹/海域）、所属、人口 |
| **event** | 时间线 | 年份 | 参与者[]、地点、后果 |
| **species** | 分布卡 | — | 智力、体型、栖息地 |
| **artifact** | 物品卡 | — | 持有者、能力摘要 |

字段类型约定：`string | number | boolean | string[]（枚举或引用 id）`。  
引用型字段在 UI 上是 **链接**（点击 → 选中实体并高亮地图锚点）。

### 2.4 序列化

- 并入 `World`：`lore?: WorldLore`；旧存档无字段则 `ensureLore(world)` 初始化。
- 与 `regions` 一样走 History（实体/关系的增删改可 undo）。
- 导出：GeoJSON `properties.loreRefs`、SVG 元素 `data-entity`；完整 JSON 含 `lore`。

## 3. 地图主舞台：丰富度与编辑

地图仍是「一切产生的地方」。在现有语义层之上补：

### 3.1 对象类型（地图上的东西）

| 对象 | 数据 | 编辑 | 显示 |
|------|------|------|------|
| 语义 Region | 已有 cell 集 | 笔刷/填充/权重/吞并 | 色块+边界 |
| 路径 | 已有 PathFeature | 控制点 | 路/河/航样式 |
| **POI 图钉** | `place`/`person` 锚点 point | 拖放、吸附到 cell 中心/首都 | 针脚+短名 |
| **范围锚点** | entity→region/cells | 与 Region 绘制共用笔刷 | 选中实体时描边+内阴影 |
| 标签（短） | entity.shortName | 显示开关、避让 | 沿锚点 |
| 图例/比例尺/罗盘 | 视图对象 | 显示开关 | 角落组件 |

### 3.2 编辑功能增量（相对现状）

| 优先 | 功能 | 说明 |
|------|------|------|
| P0 | **从地图创建实体** | 点空白「+」或快捷键：选 kind → 若在 Region 上则自动 `anchors:[region]`；若点空海则 `point` POI |
| P0 | **选中联动** | 工作区选实体 ↔ 地图高亮全部 anchors；点地图 POI/Region ↔ 打开专视图或卡片 |
| P0 | **POI 放置与拖动** | 点击放钉；拖动改 lon/lat；可「对齐到首都 centerCell」 |
| P1 | **范围笔刷直接建国家** | 现有国家绘制 + 一键「生成国家实体」填政体/首都 |
| P1 | **路径挂实体** | 商路/远征 → `path` anchor + 关系 `trade`/`rules` |
| P1 | **标签** | 仅实体 shortName，不做过载制图字体引擎 |
| P1 | **图例多组** | 按当前焦点层+实体 kind 生成；可钉住多份 |
| P2 | **测量工具** | 多点大圆 km；与比例尺联动 |
| P2 | **战争迷雾 / 对玩家隐藏** | 实体或 Region 的 `playerHidden` 属性，导出可剥离 |
| P2 | **时间线 scrub** | 调 `calendar.year` → 仅显示 `startYear≤y` 的关系/事件锚点 |

### 3.3 与笔刷/路径的关系

- 语义笔刷逻辑不变；**高度层**极地已有陆地格（见本轮代码）。
- 路径仍是「1 元素 = 1 曲线」；在专视图里路径实体与 PathFeature 1:1 显示。
- 不在本阶段引入「路径自动生成路网」（可作后续生成器）。

## 4. 专视图 UI 详细设计

### 4.1 共用壳层：`EntityShell`

所有专视图共用：

```text
┌──────────────────────────────────────────────────────────┐
│ [返回地图]  国家  ·  12 个实体   搜索…   [+新建]  ⋯       │
│ 显示： ◉ 横排卡片  ○ 侧栏页签  ○ 网格        排序：名称 ▾  │
├──────────────────────────────────────────────────────────┤
│                     内 容 区（每 kind 不同）                │
├──────────────────────────────────────────────────────────┤
│ 底：选中实体条（色点 名称 · 锚点摘要 · [在地图高亮] [编辑]）│
└──────────────────────────────────────────────────────────┘
```

- **显示模式**（`viewPrefs`）三选一：`cards-row` | `side-tabs` | `grid`；仅影响布局 DOM，不改数据。  
- 左侧页签模式：`side-tabs` 时内容区改为 `左页签列 + 右单卡大图`。  
- 快捷键：`1..9` 切 kind；`M` 回地图；`/` 搜索实体。

### 4.2 国家界面（样板，优先实现）

**数据主视图 = 国家卡坞**

#### A. 横排卡片 `cards-row`（默认）

```text
┌─────────────────────────────────────────────────────────────┐
│ 国家 · 显示[横排|页签|网格]                                   │
│ ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐             │
│ │ 🟢 A 王国│ │ 🔵 B 共和│ │ 🟠 C 汗国│ │ ⚪ D 流亡│  → 可横向滚 │
│ │ 政体:君主 │ │ 政体:共和 │ │ 政体:部落 │ │ 无领土   │             │
│ │ 首都:铁湾 │ │ 首都:白港 │ │ 首都:—   │ │ 锚点:POI │             │
│ │ 附庸 2   │ │ 盟 1 敌 1│ │ 战争中   │ │          │             │
│ │ [地图][⋯]│ │ [地图][⋯]│ │ [地图][⋯]│ │ [地图][⋯]│             │
│ └─────────┘ └─────────┘ └─────────┘ └─────────┘             │
│ 选中 B 时下方展开详情：字段表 | 关系列表 | 人物成员 | 锚点     │
```

- 卡片固定信息密度：色点、名称、政体、首都、关系徽章（盟/敌/附庸数）、领土 cell 数。

```text
┌──────────┬──────────────────────────────────────────────┐

│ ○ B 共和 │  政体     [君主制        ▾]                  │
│ ○ C 汗国 │  首都     [铁湾          ▾]（链到 place）    │
│ ○ D 流亡 │  格言     [血与火                         ]  │
│ + 新建   │  人口     [120 万                        ]  │
│          │  ── 关系 ──                                │
│          │  附庸  [● 甲侯国] [● 乙伯国]                │
│          │  敌对  [● C 汗国]                          │
│          │  同盟  [○ B 共和]                          │
│          │  ── 人物 ──                                │
│          │  [头像] 女王 E   [头像] 将军 F              │
```

- 页签宽 200–240px；当前项左侧色条 = 国家色。  
- 字段即时保存（debounce 400ms）或显式「保存」与现有信息弹窗一致（建议显式保存 + 脏标记）。

#### C. 网格 `grid`

卡片等宽两列，适合 8–20 国总览；单卡信息量少于 A。

#### 国家卡可编辑内容

| 区块 | 控件 |
|------|------|
| 身份 | 名称、色、短名、emoji、summary |
| 政体/人口/格言 | 文本/下拉 |
| 首都 | 下拉 place 实体或「设为首都」拾取地图 |
| 关系 | 从关系图或列表添加；复用 `diplomacy.ts`（suzerain/enemy/ally）写入 `Relation` 并同步 Region.attributes 兼容字段 |
| 成员人物 | 多选 person；或在人物卡上选所属 |
| 自定义字段 | 「+ 字段」添加 string/number/标签 |

### 4.3 人物关系图

```text
┌─────────────────────────────────────────────────────────────┐
│ 人物 · 关系图   布局[力导向|按国轨道] 筛选[全部|A国|…]         │
│                                                             │
│            (父) 王 E ──spouse── 王后 G                       │
│               │parent                                        │
│               ▼                                             │
│          (子) 王子 H ──rival── 将军 F ──member── A 王国       │
│                                             │rules          │
│                                          [A 王国节点]        │
│                                                             │
│  点节点：下方高亮实体卡；「在地图」→ 闪烁 anchors             │
│  点边：显示 label/年代；可改 type                            │
└─────────────────────────────────────────────────────────────┘
```

- **节点**：头像/色点 + 短名；所属国用外环颜色。  
- **布局**：  
  - `force`：简单斥力-弹簧（前端 150 节点内）；  
  - `orbit-country`：国家作中心环，人物绕所属国；  
- **交互**：单击选中（联动地图）、双击进人物卡、拖节点固定、滚轮缩放画布。  
- **边**：颜色按 RelType（盟绿/敌红/亲缘琥珀/隶属灰）；双击改类型。  
- **与地图**：底部「在地图上高亮 E 的出生地/活动区」。

人物卡（`side-tabs` 同构）：生卒年、职业、特质[]、所属、头像、anchors（place/region）。

### 4.4 其它 kind 的专视图（同壳，内容块不同）

| Kind | 内容区 | 与地图关系 |
|------|--------|------------|
| culture / religion / species | **分布卡**：小地图（只显示该实体 cell/region）+ 要点字段 + 相邻实体列表 | 小地图与主图同色 |
| organization | 成员关系小图 + 总部 POI | 总部高亮 |
| place | 单卡 + 主图飞到 POI | 必有锚点 |
| event | **时间线泳道**（按年横轴，点事件跳地点） | 事件 anchors |
| path 类 | 曲线预览 + 挂靠实体 | 主图隐藏/显示该路径 |

### 4.5 显示模式切换的技术约束

- 三种模式 **只切换内容区布局组件**（`CountryDockRow` / `CountryTabs` / `CountryGrid`），props 同为 `entities[] + selectedId`。  
- 每 kind 声明 `preferredView` 与 `allowedViews`（如 person 只有 `graph | grid`）。  
- 偏好存 `WorldLore.viewPrefs` + localStorage 覆盖（防 #1824 类「样式写死丢失」）。

## 7. 渲染与性能约定

- 实体高亮：**overlay 或 borders 插件**，不重算全图 fill（复用 borderCache/owner 环）。  
- POI：视口内 symbol 实例化，>500 时聚合（P2）。  
- 关系图：Canvas 或 SVG 皆可；节点 &lt;200 用 SVG 便于点击。  
- 专视图打开时：**主图可挂起 rAF** 或只保留小地图缩略（省内存）。  
- History：`CreateEntityCommand` / `UpsertRelationCommand` / `PatchEntityCommand`（COW 风格，与 Region 命令同构）。

## 8. 数据迁移与兼容

1. `deserializeWorld` → `ensureLore`：空 `WorldLore`。  
2. 既有 `diplomacy`（suzerain/enemy/allies in Region.attributes）**双向同步**到 `Relation`（读旧写新，或迁移脚本一次性写）。  
3. 既有 Region name/description → 可选生成 `WorldEntity`（手动「升格」优先，避免垃圾实体）。  
4. formatVersion +1。

## 10. 风险与取舍

| 风险 | 缓解 |
|------|------|
| UI 面膨胀 | 强制共用 EntityShell；每 kind 只做一种主视图 + 一种备用 |
| 实体与 Region 双源不一致 | 以 anchor.regionId 为准同步；禁止静默删 Region |
| 关系图性能 | 人数&gt;200 切按国轨道布局；默认只显示当前筛选 |
| 过度文档化 | 无全局富文本；summary ≤ 200 字，长文外链 |
| 与「成图美」冲突 | 标签/图例从简；素材库明确 P2 外 |
