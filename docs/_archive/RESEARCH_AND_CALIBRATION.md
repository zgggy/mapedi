# 参考产品调研与设计校准

> 目标：一切服务于「**轻松方便地画出详细丰富的地图，并以好看且符合世界的形式展示**」。  
> 调研对象：Azgaar FMG、Wonderdraft、Inkarnate、Dungeondraft（后两者同类启发）。  
> 问题：我们的设计是否合理？该抄什么、该避什么？

---

## 1. 他们怎么做好「好用 + 好看」

### 1.1 Azgaar FMG（开源、Web、程序化）

| 维度 | 做法 | 对我们的启发 |
|------|------|----------------|
| 入口 | 打开即 **New Map**，立刻有可玩世界 | 首屏必须 2s 内出图，不能先填一堆表单 |
| 信息架构 | 顶栏菜单：**Layers / Style / Options / Tools** | 「层 / 样式 / 参数 / 工具」四分；生成参数收在 Options，不占画布 |
| 图层 | 复选显示：height、biomes、states、religion、routes… | **显示开关**与**编辑焦点**分离：能叠着看，也能只编一层 |
| 工具 | 工具集中：编辑 borders、河流、标记、burg | 工具按「对象类型」分组，不按「算法步骤」分组 |
| 数据 | 细胞（Voronoi）+ 区域；可导出 GeoJSON | 我们的 Cell/Region 方向正确 |
| 性能 | 有专门 performance tips（降密度、关层） | 密度与显示层可开关，是产品需求不是工程师私货 |
| 架构（官方） | **world data / generators / editors / renderers** 四层 | 与我们 DESIGN_SPEC 一致；**编辑器=受控变更世界状态** |

Azgaar 弱点（我们要避开的）：UI 偏「程序参数面板」，好看度弱于绘画向工具；球面/星球不是重点。

### 1.2 Wonderdraft（买断、桌面、绘画向）

| 维度 | 做法 | 对我们的启发 |
|------|------|----------------|
| 陆地 | **笔刷画陆地 + 海岸自动美化** | 「画」优先于「填参数」；海岸要有自动打磨 |
| 符号 | 树/山 **成组撒点**（paint symbols） | 植物/动物层：**符号刷**比只填色更「丰富地图」 |
| 河流道路 | **几下点击画出有美术感的河/路** | 道路/河要有默认美化宽度与样式，不只是拓扑 |
| 主题 | **预置地图主题**（配色/纸纹/字体） | 颜色集要少而精、一键整图气质 |
| 标签 | 预置标签样式 | 标注是「好看」的关键路径 |
| 尺寸 | 512–8192px 画布心智 | 我们是星球，但「可导出高清」仍是卖点 |

Wonderdraft 是「像画家一样做图」；我们是「像地理+政治编辑器」，但**默认审美不能差**。

### 1.3 Inkarnate（SaaS、资产库）

- 大量 **可盖章资产**（建筑、植被、怪物）  
- **线/面工具** + 纹理填充  
- 高分辨率导出（8K）  
- 用户原话：*intuitive / looks GORGEOUS / easy*  

启发：没有美术资产也能「好看」→ 依靠 **样式系统 + 符号语言 + 标注**；我们不必 3 万贴图，但要有 **符号与主题的最小成套**。

### 1.4 Dungeondraft（地城，交互范本）

- **Unintimidating UI**、智能铺贴、智能撒物件  
- 工具少而准，降低上手成本  

启发：默认界面只露出「你现在会用的」；高级藏进二级。

## 2. 核心目标拆解

> **轻松方便的绘制** + **详细丰富** + **好看** + **符合世界**

| 目标 | 含义 | 产品对策 |
|------|------|----------|
| 轻松 | 少模式、少面板、笔刷直接 | 选层→点元素→画；快捷键；所见即所画 |
| 详细丰富 | 国家/省/河/路/群系/文化…可堆叠 | 图层语义 + 符号 + 标注，不只是色块 |
| 好看 | 不像调试工具 | 主题、海岸、河路美术、标注、导出 |
| 符合世界 | 球面正确、气候说得通 | 球面真相 + 气候→群系 + 邻接拓扑 |

**结论**：我们前一阶段把大量力气花在「拓扑正确 + 编辑器骨架」，这正确；但离「轻松 + 好看」还差一截，下一步应补 **绘画感与显示完成度**，而不是继续堆面板架构。

## 3. 我们现有设计：合理 vs 偏差

### 3.1 合理、应坚持

| 设计 | 依据 |
|------|------|
| Cell 为最小粒度 | Azgaar 同源；适合行政/道路语义 |
| 球面为唯一真相 | 「符合世界」的硬保证 |
| 图层 = 语义层，不只是贴图 | 比 Wonderdraft 更「世界书」 |
| 生成与绘制分离 | Options/生成 vs 画布工具，同 Azgaar 菜单逻辑 |
| 焦点层 + 工作台 | 减少模式切换，符合「轻松」 |
| 颜色集 / 主题 | Wonderdraft 验证过「一键好看了」 |
| 窄 UI、不挡地图 | 绘画类工具共识 |

### 3.2 偏差或不足（相对「轻松+好看」）

| 问题 | 表现 | 校准 |
|------|------|------|
| **编辑粒度偏「选 Region 再刷 cell」** | 打开后不知道从哪画 | 要有「默认可画」：高度笔刷一直可用；或「从这里长大陆」 |
| **符号层缺失** | 只有颜色，没有 🌲🏔️🏙️ 的「丰富感」 | 植物/城市：**符号撒点**（Wonderdraft 核心体验） |
| **标注完成度低** | 有国家名但不成套 | 字体/描边/层级预设；首都特殊符号 |
| **海岸与河路美术** | 拓扑对但不好看 | 海岸描边、河宽随级、道路 casing |
| **生成参数仍偏工程** | 密度、falloff | 对外文案改「大陆数量/崎岖度」；高级折叠 |
| **球面 vs 2D 切换成本** | 心智负担 | 默认 2D 创作，球面为「星球预览」；切视图不改数据（已正确） |
| **信息密度过载** | 层太多、按钮多 | 按用户故事折叠：自然 / 政治 / 交通 |

## 4. 目标 UX 脚本（推荐默认路径）

```text
打开应用
  → 自动一张 2500 cell 小世界（已有高度+简单国家）
  → 焦点层 = 高度，左键即可刷陆地/海洋
  → 右栏「工作区」：当前层工具 + 相关元素列表
  → 想画国家：点 👑 → 列表点国家或 ➕ → 🖌️ 绘制 → 刷行省
  → 想丰富：🌿 植物 → 符号刷在适宜群系上撒树
  → 想好看：设置→视图→主题（羊皮纸/暗色…）→ 导出 PNG
  → 想星球：🌐 球面预览（不可编辑或弱编辑均可，但颜色一致）
```

原则：**默认就能画**；「先生成再进编辑」是可选入口，不是唯一入口。

## 5. 架构 / 算法 / 渲染校准

### 5.1 架构

坚持四层（同 Azgaar 官方）：

```text
WorldData（无逻辑） ← Generators / Editors → Renderers（只读）
```

- **Editors** 只暴露「用户动作」：paintHeight、assignCell、setCenter…  
- **Renderers** 禁止写数据（我们已基本做到）  
- UI 只调 Editor API  

### 5.2 算法

| 模块 | 校准 |
|------|------|
| Voronoi | 已较正确（全局对偶）；保持 |
| 高度 | 保留噪声大陆 + **增加海岸线美化**（更细噪声叠层） |
| 河流 | 级联宽度已是方向；补 **河口三角洲/湖** 可后置 |
| 气候→群系 | 保留；UI 把参数译成「更冷/更湿/更多氧」 |
| 政区 | 保留；默认国家数随陆地面积自动 |
| 符号 | **新增**：植物/城市符号密度场（群系+高度+河谷） |

### 5.3 渲染

| 通道 | 要求 |
|------|------|
| 陆地 | 高度色带或群系色 + hillshade 可选 |
| 海 | 渐变深浅 + **海岸线描边**（好看关键） |
| 河 | 随河级变宽，圆头 |
| 路 | 双线 casing 或虚线 |
| 符号 | 树/山/城 icon，随 zoom LOD |
| 标注 | 描边、层级、首都星标 |
| 主题 | 2–3 套一键切换（已有，增强对比度） |

球面：继续 **无高度、同色**；符号可先 2D 贴图烘焙，不必一上来 3D 点云。

## 6. 工具设计校准

| 工具 | 从参考学到的 |
|------|----------------|
| 高度笔刷 | Always-on；滚轮改半径；海洋/陆地两色 |
| 符号笔刷 | 植物/城市：密度滑条 + 随机缩放旋转 |
| 边界笔刷 | 政区边缘微调（Azgaar borders） |
| 填充 | 已有；默认「到海岸/到异界」 |
| 套索 | 批量归属 |
| 选择 | 点 cell 显示所有层归属（信息 Peek） |

**快捷键**：B 笔刷、E 橡皮、I 吸取、F 填充、H 隐藏 UI（出图模式）。

---

## 7. 操作方式（用户手顺）

1. **默认可画**：焦点=高度，无需先点绘制按钮  
2. **画元素**：点 🖌️ 才进 Region 绘制会话（避免误改）  
3. **右键**：Peek 归属 / 吸取  
4. **Ctrl**：重叠分摊；**Shift**：移除  
5. **Esc**：退出绘制 / 关闭 Peek  
6. 球面：默认只读预览，避免 3D 拾取不稳定破坏「轻松」

## 8. 优先级（相对上一版 DESIGN_SPEC 的修正）

| 优先级 | 项 | 原因 |
|--------|----|------|
| **P0** | 稳定出图 + 默认高度可画 | 「轻松」的第一步 |
| **P0** | 海岸线/河路基础好看 | 「好看」最低门槛 |
| **P1** | 主题对比度与标注预设 | Wonderdraft 验证路径 |
| **P1** | 焦点层工作台稳定（列表+画） | 「详细丰富」的编辑路径 |
| **P2** | 符号撒点（树/城） | 丰富感跃升 |
| **P2** | 群系色与符号联动 | 符合世界 |
| **P3** | 球面符号/光照 | 锦上添花 |
| **P3** | 25k 性能 | 产品默认不必顶格 |

---

## 9. 总判

- **合理**：cell 拓扑、球面真相、图层语义、生成/绘制分离、窄 UI——这些扛得住对标。  
- **需要纠偏**：从「工程编辑器」转向「**默认能画、画完像图**」。  
- **产品北极星**：用户打开 30 秒内刷出一条海岸，10 分钟内有一个「像世界」的截图可分享。

下一步实现顺序建议：**P0 出图与高度笔刷手感 → 海岸/河好看 → 主题/标注 → 符号刷**。
