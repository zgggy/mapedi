# Mapedi 最新需求与设计方案

> 版本：v1.0（相对早期 REQUIREMENTS.md 的收敛稿）  
> 说明：以下以**你后续口头修正**为准，覆盖文档里仍写着但已作废的项（近景 3D、多投影、悬浮大面板等）。

---

## 一、最新需求整理（以当前共识为准）

### 1. 产品一句话

以 **球面为唯一真相** 的星球架空地图编辑器：生成 → 按图层绘制/改归属 → 在 **平面墨卡托** 与 **球面** 两种视图下**所见即所画**。

### 2. 明确收敛 / 作废

| 早期 | 现在 |
|------|------|
| 五种投影互转 | **只保留墨卡托**（平面） |
| 近景 3D、球面 3D 高程 | **删掉**；球面**不显示高度** |
| 复杂悬浮面板、角点收纳 | **不要**；窄侧栏 + 紧凑 UI |
| 全局三态「观看/生成/绘制」大模式锁 | **生成**与**绘制**分离：生成在设置里，绘制是工作区工具 |

### 3. 核心领域

- **Cell**：最小粒度；球面 Voronoi 后固化为多边形；海洋也是 cell  
- **图层（Layer）**：高度、环境（冻土/雪/林/原…）、植物、动物、种族、文化、宗教、国家、行省、道路、航线、军队（预留）  
- **Region**：层内元素；可重叠（权重）、可父子（国家⊃行省）、可要求相邻（道路）、可要求中心（首都）  
- **生成**：按层参数一键/单层重算；气候参数（倾角、自转、含氧、基准温）驱动环境与生物  
- **绘制**：笔刷/套索/填充/中心；抢占或 Ctrl 分摊权重；国家绘制落到行省  

### 4. 显示

| 视图 | 说明 |
|------|------|
| **平面** | 墨卡托俯视，完整编辑 |
| **球面** | 同一套 cell 多边形贴球，**无高度**；同一套绘制与着色规则 |

球面必须：与 2D **同色、同拓扑、可绘制**；进入要快。

### 5. UI（最终形态）

```
┌36┬──────────────────────────────┬36┐
│📚│                              │⚙️│
│左│        地图视口              │右│
│栏│         （全高）             │栏│
│  │                              │🛠️│
├──┴──────────────────────────────┴──┤
│ 左下：半透明状态条                  │
│        底部中：半透明绘制 HUD       │
└─────────────────────────────────────┘
```

- 左栏：仅 **图层**  
- 右栏：**设置**（生成/视图/项目）+ **工作区**  
- 面板 **窄**（约 250px），padding 小，**不占半屏**  
- 开合：点已开→关；点**同侧**另一钮→切换  
- 列表行：名字 + ℹ️ 🖌️ 🗑️（+子层展开）  
- 无滚动条露底、无双层面板叠字  

### 6. 交互与绘制

- 左键刷入；Shift 减；Ctrl 与所有占有方分权重  
- 画国家时地图显示行省色块（所见即所画）  
- 笔刷圆虚线跟随  
- 删除元素：**不删子元素**；吞并可撤销  
- 默认密度约 **2500**（性能优先；更高需解锁）  

### 7. 非目标（维持）

完整战略模拟、多人协作、移动端精修、多投影 GIS。

## 二、核心需求分析（我们到底在解决什么）

用户真正要的是三条主轴，其它都是支撑：

1. **正确的世界拓扑**  
   球面 cell 必须无缝、可邻接、极区不是奇异点；否则河流/道路/行政连通全是假的。

2. **图层语义可编**  
   不只是「好看的地图」，而是「国家 / 行省 / 宗教 / 道路」等**可增删改、可父子、可重叠**的数据；UI 必须为「选层 → 看元素 → 画/改」服务。

3. **两种视图同一套语义**  
   平面与球面只是镜头；编辑语义、颜色、拾取必须一致，否则用户无法建立心智模型。

次要但决定手感的：**生成要快到能迭代**、**笔刷跟手**、**UI 不挡地图**。

## 三、目标架构（怎么长）

### 3.1 分层

```text
┌──────────────────────────────────────────┐
│ UI Shell（竖栏 + 窄侧栏 + 状态/HUD）      │
│  仅交互与展示，无世界逻辑                 │
├──────────────────────────────────────────┤
│ EditorSession（store.svelte.ts）          │
│  焦点层、选择、绘制会话、历史、校验触发   │
├───────────────────┬──────────────────────┤
│ Render 2D Mercator│ Render Globe         │
│ 同一 cellColor    │ 同一 cellColor       │
├───────────────────┴──────────────────────┤
│ Core（纯 TS，无 DOM）                     │
│  World / 图层 / Region / 生成 / 索引      │
├──────────────────────────────────────────┤
│ Persist（IndexedDB + 文件导入导出）       │
└──────────────────────────────────────────┘
```

### 3.2 数据不变量（写进代码与文档）

1. **几何真相**：cell 顶点 = 球面点（lon/lat 或单位向量）；投影坐标仅缓存。  
2. **归属真相**：`Region.cells`；权重可选。  
3. **邻接真相**：由全局 Delaunay 对偶得到的边，不是「最近邻凑合」。  
4. **显示**：`cellColor(world, cellId, focusLayer, fills)` **唯一函数**；2D 与球面共用。  

### 3.3 EditorStore 要求

- 状态放 **模块级 `$state`**，组件用 `$derived` 读  
- **禁止**在 `$effect` 里写会再触发同一 effect 的 state（已踩过 `effect_update_depth_exceeded`）  
- 提交绘制用 History 命令；笔刷过程中只做轻量索引失效

## 四、算法架构

### 4.1 地块（Cell）

```text
blueNoiseSphere(n)          // 蓝噪声撒点，有机、无格点感
  → sphericalVoronoi        // 全局 Delaunay 外心，共享顶点，无缝
  → weldVertices            // 浮点保险
  → 存 polygon: LonLat[]    // 球面真相
```

要点：

- **必须**全局三角形 + 共享外心，不能每站各自拼胞腔（会缝、会洞）  
- 允许钝角外心，否则对偶出现小洞  
- 邻接 = Delaunay 边；稀疏处网格 kNN 补齐  
- 性能：n≈2.5k 流畅；25k 可生成但 UI 默认不加载  

### 4.2 地形与自然

```text
高度：噪声+域扭曲大陆 + 热侵蚀
河流：D8 + 流量累积 → Edge.river
气候：倾角/自转/含氧/基准温
      → 温度、降水、风带
环境：Whittaker 近似（冰盖/雪地/冻土/针叶/森林/草原/沙漠/雨林/湿地…）
植物/动物/种族：按群系+气候采样扩张
```

### 4.3 人文与交通

```text
文化/宗教：多种子 + 成本 BFS（山、河屏障）
国家：沿海优选 + 成本扩张 → 行省递归
道路：首都 MST + kNN + A*
航线：港口大圆 + 避陆
```

统一接口：`LayerGenerator { layerId, dependsOn, defaultParams, generate(ctx) }`

### 4.4 绘制与拓扑

- 笔刷命中：CellGrid 大圆半径（勿用经纬平面平方）  
- 抢占 / Ctrl 分摊：写 `Region.cells` + `weights`  
- 道路：邻接成折线；端点拖出改归属  
- 校验：父子包含、连通、中心、权重、道路断裂  

### 4.5 明确不做（算法）

- 完整 GCM、板块构造全模拟、25k 默认全图编辑性能冲刺（除非产品要求）

## 五、渲染设计

### 5.1 双后端、单着色

| 后端 | 技术 | 说明 |
|------|------|------|
| 平面 | Canvas2D | 墨卡托；视口裁剪；fill 缓存；小 cell 可省描边 |
| 球面 | Three.js | **仅** r=1 球面 mesh（或纹理）；**无高度**；MeshBasic 省光 |

着色：`cellColor()` 与层 fills（country/province/layer/biome）同一套。

### 5.2 球面

- 用 **cell 多边形三角扇** 或 **等距柱状纹理**，禁止每帧全量重建  
- 绘制中不 rebuild；`commitStroke` 后按 `rev` 防抖重建  
- 拾取：隐形 r=1 球射线 → lon/lat  

### 5.3 平面

- 投影缓存（含 bbox）  
- 视口 culling  
- 拖动时可降级（不画标注）  
- 笔刷圆：屏幕空间 stroke  

### 5.4 性能预算（当前目标）

| 项 | 目标 |
|----|------|
| 首屏出图（2500） | &lt; 2s |
| 2D 拖拽 | 可用（&gt;30fps 可接受） |
| 球面进入 | &lt; 1s（不卡死） |
| 笔刷跟手 | 每 stroke 一次 History，不每帧全图重建 |

## 六、工具与操作设计

### 6.1 模式（取代旧「三态」）

```text
浏览（默认）
  选择图层、点选元素、缩放平移

绘制会话（点元素 🖌️ 或工作区「绘制」）
  笔刷 B / 套索 R / 权重 W
  Shift 减、Ctrl 分摊、Esc 退出
  国家 → 作用于行省

生成（设置 → 生成）
  种子、密度、分层参数、「重新生成」
```

### 6.2 工作区结构（右栏）

```text
工具区（按焦点层）
  高度：半径、填充、撤销（无元素列表）
  其它：绘制 / 吞并 / 填充 / 中心 / 撤销 / 半径

元素区（按焦点层 kind）
  平铺列表 或 父子嵌套盒
  行：色块 名字 ℹ️ 🖌️ 🗑️ [▸子层]

新增区
  名称 🎲 ➕
```

### 6.3 设置（右栏）

- **生成**：种子、密度、级联、分层 profile  
- **视图**：平面/球面、颜色风格、（平滑可留作将来）  
- **项目**：导出、导入、搜索、测距  

### 6.4 信息面板

点 ℹ️：名称、颜色、描述、保存；不塞进拥挤列表行内。

### 6.5 快捷键（草案）

`B/R/W` 工具 · `Esc` 退出绘制 · `Ctrl+Z` 撤销 · 视口拖拽/滚轮

## 七、UI 设计原则（避免再翻车）

1. **窄**：侧栏 240–280px；控件 padding 4–8px；字号 12px  
2. **不抢镜头**：状态条、HUD 半透明贴边/贴底  
3. **一层内容**：禁止 overlay 叠假列表（FloatingPanel 空 body 那种坑）  
4. **同侧互斥开合**；不要「随便飘」的窗口  
5. **Emoji 图标**；破坏性操作有文案  
6. **无自定义滚动条噪音**；列表内部可滚即可  
7. **Svelte 响应式纪律**：effect 只读；可变状态进模块 `$state`

| 优先级 | 项 | 说明 |
|--------|----|------|

| P3 | 25k 稳定可编辑 | 先 WASM/Worker，不先加功能 |
| P3 | 导出质量 | SVG/GEOJSON 与样式一致 |

## 九、一句话总结

**球面拓扑 + 图层语义 + 双视图同一套绘制** 是核心；UI 只做「选层 → 看见元素 → 画进地图」；算法与渲染都为「快、准、可改」服务，不为展示花活服务。
