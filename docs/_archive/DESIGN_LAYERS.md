# Mapedi 显示图层系统 · 实施规格

> 状态：**可实施** · 2026-09-23  
> 取代：旧「子层须被父层完全包含」校验；层父子 = **仅显示**，不改 cell 数据。

---

## 1. 规则（已拍板）

| 项 | 规则 |
|----|------|
| 真相 | **Cell**；Region = 某层上的 cell 集合。显示父子 **不写回** Region 归属 |
| 显示父子 | 任意层可挂到任意层下（**禁环**）；**不做包含校验** |
| 同时显示 | 最多 **3** 个「颜色根树」；父+子 = **1 个名额**（父定颜色，子在父内细分） |
| 自由层 | 道路/航线/河流 **不占** 名额，可独立显隐 |
| 层序 | 列表顺序 = 上下关系；**最下不透明**，越往上默认越透明（可调） |
| 对比度 | 列表 **越靠上** 的层颜色区分越鲜明；越靠下对比度越低 |
| 子在父外 | 合成 **虚拟父 `—`**：显示为 `c(—)`，只影响绘制 |
| 多父切割 | 子元素与多个父 Region 相交 → 多个碎片 `c(A)`、`c(B)`（英文括号） |
| 多层切割 | 祖先链每级都切：`r(c(A))`（自内向外套括号） |
| 点击 | **显隐** 开关；显示中 = 彩色边框，隐藏 = 灰边框 |
| Hover | 浮出 **「绘制」** 按钮 → 打开工作区并聚焦该层 |
| 绘制时 | **当前选中层** 作颜色区分层；其它可见层一律当底（降对比），即使它是父层或列表更上 |

---

## 2. 名额与可见性

```text
显示树根 root（无可见 parent）计 1 名额
  └─ 子层（显示 parent）随根显示，不另计

自由层 kind ∈ {road, route, river}：始终可显，不计名额

开启第 4 个根时：拒绝并提示，或挤掉列表最下的根（v1 = 拒绝提示）
```

默认：`height` 可见；其余 cell 根默认关；自由层默认开。

---

## 3. 合成标签与碎片

```text
父层 Region：A, B
子层 Region：a⊂A, b⊂B, c 与 A、B 相交，另有格不在任何父内

显示碎片：
  A, B                         （depth 0，色=国家）
  a(A), b(B), c(A), c(B)       （depth 1，色=文化，透明度↑）
  c(—)                         （虚拟父，可选显示）

三层（国家 ⊃ 文化 ⊃ 宗教）时：
  r(c(A)), r(c(B)), r(b(B)), … （depth 2）
```

- 标签仅用于图面/图例；数据实体名仍是 `c`、`r`。  
- 编辑笔刷仍改整条 Region 的 cell 集，**不按碎片编辑**。

---

## 4. 透明度与对比

| 树内深度 | 默认 alpha | 默认对比 |
|----------|------------|----------|
| 0（根） | 1.0 | 100% |
| 1 | 0.62 | 75% |
| 2+ | 0.42 | 55% |

- 层 `opacity` 可覆盖默认（0–1）。  
- 多棵可见树：按列表 **从下到上** 叠画；同格像素 = 上层色 × 上层 alpha 叠在下层上。  
- **绘制焦点层**：该层树用满对比；其余可见树 `contrast × 0.45`。

---

## 5. 交互

```text
图层 box
  ├─ 单击          → 显隐
  ├─ hover         → [绘制] [⋯]
  ├─ [绘制]        → focusLayer = 该层，打开工作区
  ├─ 拖拽 nest     → 仅改显示 parentLayerId（禁环）
  └─ 拖拽 gap/root → 调列表顺序 = 上下顺序
```

边框：`visible` → `1px solid 层强调色`；否则 `1px solid var(--panel-border)`。

---

## 6. 数据字段（LayerDef）

```ts
parentLayerId?: string;  // 显示父（已有）
visible?: boolean;       // 默认见 §2
opacity?: number;        // 0–1，可选覆盖
```

序列化随 `layers`；旧档缺省按 §2 补。

---

## 7. 与 Region.parentId 的分工

| | Layer.parentLayerId | Region.parentId |
|--|---------------------|-----------------|
| 含义 | 显示合成树 | 数据行政（国家⊃行省） |
| 校验 | 仅禁环 | 保持现有 |
| 影响 | 怎么画、标签 | 归属/吞并/工作区树 |
