> **定位**：UI 重构实施规格。来源 = 用户 2026-09-29 六条需求（原文语义保留，优化处标注）+ 同日两轮 UI 评审。

## 2. 顶栏

### 2.1 模式胶囊（需求 1）

- **视觉**：复用胶囊滑块语言——大胶囊内两个档位 `[ 🌐 球面展示 | ✏️ 平面绘制 ]`，填色小胶囊停在哪侧即当前模式；**两侧文字常驻**（读作分段开关，不是滑块）。
- **交互**：点击对侧切换；支持沿轨拖动（复用胶囊手感，可选增强）；键盘 Tab 聚焦 + ←→ 切换。
- **实现**：CapsuleSlider 整数离散模式（2 档）或其变体；未来加模式 = 加档位（离散多档天然扩展），超过 3 档再评估换分段控件。第三个模式的 `◻` 空占位钮删除——占位属于代码不属于 UI。
- **位置**：顶栏中央悬浮（固定宽，top≈12px），不与左轨/世界名重叠。
- **切换连带行为（规格）**：
  1. 绘制会话指针按下中 → 忽略切换；松手状态切换 → 以 Esc 语义先退出会话。
  2. 每模式各自记忆相机（球面姿态 / 平面 camera 互不覆盖）。
  3. 左轨保持打开，内容按模式过滤（§3.4）。
  4. 状态栏模式段同步 + 一条切换反馈。

### 2.2 世界名菜单（原项目面板 · 文件部分）

- 顶栏右端世界名 pill，点击弹菜单（复用 ContextMenu 组件）：导出 .mapedi.json / 导出 .gz / 导出 PNG / 导出 SVG / 导入… / 清除自动存档；菜单头部显示"自动保存 HH:MM:SS"。
- **世界改名（D2 已拍板）**：**双击**世界名 → 原位变文本框；点击别处 → 收起并提交新名。数据触点：`WorldMeta` 现无 name 字段，需新增 `meta.name`（序列化是双向展开 `{...world.meta}`，加字段**自动往返**；旧档缺省回退显示 `世界 {seed}`）。**改名只写 meta → 走 `touchView()` + 显式 `scheduleAutosave()`**（现有 autosave 只被 `cells.length`/`regions.length` 触发，纯 meta 变更不会保存——ROADMAP 已登记该缺陷）。

### 2.3 视图设置 popover（原视图面板残余）

- 顶栏最右 ⚙ 钮 → transient popover：**投影**下拉（墨卡托/罗宾森…）+ **地图风格**下拉（暗色/羊皮纸/科幻——StyleSet 从"视图"迁入并正名，它改的是海色/陆色/描边，不是 UI 主题）。
- 球面参数**不在**此处——已迁为球面模式下的工作区内容（§3.4，D3 已拍板）。
- 与图层"显示参数"的区别：此处是全局视图（投影/风格集选择）；StyleSet 的样式细节编辑在图层右键菜单的"显示参数"popover。

## 3. 左侧工作区轨（需求 3 + 5）

### 3.1 结构与滚动模型

```
收起图层时（工作区段落次序定稿 C8）：     展开图层后：
┌───────────────┐              ┌───────────────┐
│[⊟]📚 高度 [展开]│              │[⊟]📚 图层 [收起]│
│───────────────│              │新图层 [__]🎲➕  │
│✏️笔刷B  ↶↷     │ ← 工具带(最高) │┌图层列表(内滚)─┐│
│笔刷 ──●── 1.5°  │              ││👁 🔲 地块     ││
│───────────────│              ││👁 ⛰️ 高度 ←聚焦││
│新元素 [__]🎲➕   │              ││… 15 层       ││
│🔍 过滤________  │ ← 搜索框(C4)  │└──────────────┘│
│┌元素列表───────┐│              │────工作区下浮────│
││(虚拟滚动,到底) ││              │(以下按次序同左)  │
│└──────────────┘│              │               │
│[生成 ▾] 折叠把手 │ ← 低频区     │               │
│[层设置 ▾] 折叠把手│              │               │
└───────────────┘              └───────────────┘
```

- **轨 = 视口全高（顶到底），轨本身不滚动**。两个内滚区：图层列表 max-height ≈ 45% 轨高内滚；元素列表 flex-1 内滚（虚拟列表）。——防双长列表把工具行滚出视野。
- 展开图层 → 工作区内容整体下浮（flex 布局自然实现，即需求原话）。

### 3.2 图层子面板

- 收起态 header：当前聚焦层（emoji + 名 + eye 态）+ 元素数 + [展开]。
- 展开态：CreateRow(新图层 + 🎲 + ➕) + 完整图层列表。ItemButton 全套交互保留：**eye = 唯一显隐**（契约不变）、长按拖动排序、右键菜单、双击 = 显示参数 popover。
- 行点击 = 聚焦该层 + 工作区切换上下文（原"聚焦+开工作区"语义并入单轨；实施时同步 AGENTS §6 措辞）。

### 3.3 工作区区（段落次序已定死，C8）

垂直次序 = **高频在上、低频在下**，四段：

1. **工具带（最高优先，C3/C8）**：互斥单选工具 + 笔刷尺寸胶囊滑块（° 单位）+ **undo/redo 按钮**（**D1′ 2026-09-30 用户澄清**：「不接功能 = 不接**新**功能，**已有功能可以**」→ 按钮**直接接现有 `editor.undo/redo`**，与键盘 `Ctrl+Z` / `Ctrl+Y` 同源；**新增的可撤销范围**（生成、跨元素副作用等）仍等还债步骤 1 命令化，不在本轮造新能力）。**权重笔刷（weight）删除（C3 用户定：不再被需要）**；`fill`/`center`/`road` 按功能相关性在 U2 开工时逐一裁定去留——原则：不直接服务"绘制/编辑该层元素"的工具不上带，上带的工具给真键位（消灭假快捷键）。
2. **新增元素行 + 搜索框**：CreateRow（现制）+ **元素名过滤框（C4）**——打字即过滤本层元素列表，空结果给一句提示；空列表一句话 + 动作（替代纯空白）。
3. **元素列表（主体，flex-1）**：虚拟列表 + 嵌套子层 + 行右键菜单（现制全保留）。
4. **低频折叠区（C8：生成与渲染样式优先级低于绘制工具）**，两条默认收起的把手：
   - **`[生成 ▾]` 把手**——**单击** = 展开参数子面板（轨内嵌卡片区，非浮窗）；**长按** = 进度条从左到右填满，满格**直接触发生成**（D5，复用 ItemButton 长按语义："进度未满松手 = 单击展开"天然兼容两手势）；生成中把手转进度态（细节走状态栏）；无确认对话框。
   - **`[层设置 ▾]` 把手**——展开显示该层显示参数（样式链现有控件）+ 图层信息摘要；与右键菜单"显示参数…/图层信息…"是**同一 popover 的两个入口**（内容单源）。

生成子面板（展开后）：
  - 通用层：按该层 LayerKind 的 GenConfig（`core/layer/genTypes.ts` 单源）渲染参数控件 + [生成] [取消]。
  - **高度层特殊** = 原项目面板"生成"节整体迁移：种子+🎲、地块数、大陆占比（小/中/大/特大）、落差、大陆尺度、海岸破碎、山脉、细节、海床、平整、低纬倾向、侵蚀。即"生成世界 = 生成高度层"。
  - 生成中：按钮转进度；状态栏"生成中（Worker）… n 地块"（现有机制）。
  - **破坏性**：生成替换该层现有元素。误触发防护 = 长按进度（D5）；长期可撤销依赖还债步骤 1（命令化），不阻塞本 UI。
  - 参数草稿按层持久化（`localStorage mapedi.ui.gen.*`）。
- **元素列表**：现状全保留（虚拟列表 / 嵌套子层 / 新行省行 / 右键菜单 / eye）。
- **空态**：列表空显示一句"此图层还没有元素 — 直接在地图上绘制，或点 ➕"（替代纯空白）。

### 3.4 模式过滤

- **球面展示（D3 已拍板）**：图层子面板照常（eye 显隐有意义）；**工作区区整体替换为「星球」参数区**——倾角、自转周期（自转速度）、自转预览、轴/赤道、黄道、浮雕平滑（自原视图面板迁入）；工具行、生成、元素列表不显示。
- **平面绘制**：全功能（工具行 + 生成 + 元素列表）。

### 3.5 收起

- [⊟] 收起整轨 → 左上角独立圆钮 🗂；点击还原。状态持久化（localStorage）。

### 3.6 选中与绘制契约（C1 拍板，修订第三十三次"选中即绘制"）

| 手势 | 行为 |
|---|---|
| **列表行 单击** | **只选中**（黄框 + 地图高亮 + 信息/层设置可达），**不武装笔刷** |
| **列表行 双击** | 进入绘制会话（工具带激活、状态栏提示、Esc 退出） |
| **画布 单击**（会话外） | **反选该处元素**（pickCell → 查焦点层包含归属 → 选中），与列表单击同语义 |
| **画布 双击** | 语义不变（路径草稿提交）；不定义"画布双击进绘制" |
| 绘制会话内 | 行为不变（左键笔刷 / Shift 移除 / Esc 退出） |

- **悬停归属（C4 ①）**：状态栏悬停区在 cellId/经纬/高度之外**增加所属元素名**（数据现成：`Region.cells` 反查），点击可跳选。
- **守卫**：会话内若目标层不可见 → 状态栏常驻警示 + 笔画高亮保留到会话结束（C1 配套，防"画了看不见"）。
- 同步 AGENTS §6 相关措辞（"选中即绘制"条款改"单击选中、双击进绘制"，注明日期与本轮拍板）。

## 4. 弹出层体系（需求 4）

- **统一挂载**：所有右键菜单与 popover 挂 **body 级 PopoverRoot**（fixed 定位 + `--z-overlay` token）——**根治菜单被面板 overflow 截断**（现状菜单渲染在面板 DOM 内部）。
- **边界规则**：打开前测量，上下左右 clamp 进视口（翻转优先）。
- **画布右键（C2 已拍板 2026-09-30）**：**只有面板内的行才出右键菜单；画布右键 = 纯位移**（中键改相机、右键拖动改 contentOffset 构图偏移，两者概念不同、都保留），**画布不做单击菜单**。→ 右键菜单的挂载修复只针对面板行（§4 portal 规则仍全量生效）。
- **右键菜单内容定稿**（面板行）：
  - 图层行：显示/隐藏 · 显示参数… · 图层信息… · 上移一层 · 下移一层 · 复制一个 · 删除（内置层禁删，禁删项灰显）
  - 元素行：显示/隐藏 · 元素信息… · 显示参数… · 上移/下移 · 复制 · 删除（派生元素禁复制/删除——沿现状）
- **信息/参数 popover**：从菜单项打开的浮动编辑卡（≈320px，锚定行旁、越界翻转；Esc / 点外关闭）。内容沿用现 EntityInfoBody / DisplayStylePanel，编辑语义不变。
- **退役**：图层信息、元素信息、显示参数三个常驻面板删除；PanelShell 组件保留改用作 popover 卡片壳；PanelDock 删除。

## 5. 底栏状态栏（需求 2）

三分区（视觉分组 + 语义固定）：

```
[ 上下文提示 / 操作反馈 / 错误(红) ] [ #id · 经纬度 · 高度 · 海陆 ] [ 🌐|✏️ · ×1.00 · 160 FPS · 已存 20:25 ]
        左：随事件变化                    中：悬停才显示                 右：固定仪表
```

- FPS 带单位；**预热期显示"预热中…"而非帧率数字**（防"4 帧"误读）。
- 错误类消息红色、不被普通状态覆盖至少 5s（或走 toast，见 §7）。
- 自动保存时间移右区（"已存 HH:MM"），悬停显示完整时间戳；GPU 后端标识保留右区。

## 7. 配套基建（顺带落地）

- **PopoverRoot/portal** + z-index token（`--z-canvas/--z-panel/--z-overlay/--z-toast`，替换全库 11 处裸数字）。
- **keymap 服务**：B/W 真键位、`Ctrl+Y` redo 等价键、Esc 语义统一；**无模式切换键（D6 已拍板：不要）**；? 速查面板可选。
- **toast（可选）**：错误走红色 toast；不做则按 §5 状态栏错误规则。
- **UI 偏好持久化**：`localStorage mapedi.ui.*`（轨开合 / 图层区展开 / 生成草稿 / 视图设置）。
- **模式状态机**：`shell.mode` 单源（'globe' | 'plane'），绘制会话为其派生态——批 3b 入口保留，底层收敛。
- **有效视口（C7 拍板）**：相机取景/自动定位按"未被左轨与状态栏遮挡的区域"计算；左轨开合时内容自适应重居中；**选中元素若落在遮挡区则自动平移露出**（scroll-into-view 等价）。纯显示层（相机 padding），不动数据与契约。

## 8. 实施分期（每包独立验收）

### 11.2 生成 v2：针对图层的统一递归架构（取代「总生成」）

**不再存在总的生成**。生成入口 = 工作区「生成」子面板，作用于**当前选中图层**：

| 层 | 子单位 | 生成语义 | 特殊性 |
|---|---|---|---|
| **地块（cells）** | —（自身） | **重新撒点**生成地块（种子/地块数） | 特殊①：无子层 → 撒点 |
| **高度（height）** | 地块 | 生成高度场：对地块**赋元素关系的同时赋值高度**；海陆随高度重建 | 特殊②：赋值高度 |
| **环境及以下** | 无子图层 → cell；有子图层 → 子图层元素 | 无子层：以 cell 为单元生成元素；有子层：**先生成子图层元素，再以子图层元素为单元生成本层元素（递归）** | 常规 |
| 其他不依赖地块的层 | 待设计 | **暂不做**（入口灰显「生成方法待设计」） | — |

**图层树约束**：一个图层**至多一个子图层**（不允许多个），但允许多层子图层（递归链）。

**统一模型**：`生成(层) = 单位(层) ⊗ 策略(层)`；`单位(层) = 子图层?.元素 ?? 地块`——**无子图层的元素默认拥有一个虚拟子图层「地块图层」，其元素 = 地块**。两个特例在该模型下的位置：地块层 = 没有子层的地块图层本身 → 策略 = 撒点；高度层 = 单位是地块但策略在赋归属之外还赋高度。这与整体架构**同构**：`LayerDef.parentLayerId` 本就是单父树（每层至多一个父；新增约束=每层至多一个子）、`Region.parentId` 元素树同构、`runCascade(layerId)` + `genTypes.GenConfig` 本就是「层 → 生成器 + 参数」单源——生成 v2 只是把 UI 入口收敛到层 + 把「子单位」概念显式化，**不需要新引擎**。

**实现映射**（现有单源）：地块 → `generate(seed, density)`；高度 → `regenLayer('height')`；环境/植物/动物/种族/文化/宗教/国家/行省 → `regenLayer(layerId)`；军/路/航/河 → 无生成器，入口灰显。
